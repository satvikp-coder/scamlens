# ScamLens evaluation report

_Generated by `npm run evaluate` from the real engine. Do not edit by hand._

All examples are fictional and hand-written by the developers of the rules (with an AI assistant). This is a small SYNTHETIC test set. It checks that the rules behave as designed. It does NOT measure how well ScamLens would do on real scam messages, and the numbers below must not be quoted as the accuracy of the app.

## Precision and recall

Over all 36 scam and 27 benign examples: TP=35, FN=1, FP=0, TN=27. Precision = 1.00, recall = 0.97. These are inflated because the dev and regression examples were used to write and fix the rules.

Held-out only (6 scam, 6 benign): TP=5, FN=1, FP=0, TN=6. With so few examples a single mistake changes the percentages a lot, so no precision/recall figure is quoted for this set.

## Known limitations of this evaluation

- Synthetic, hand-written examples; real messages are messier and more varied.
- Written by the same people who wrote the rules, so the examples reflect their assumptions.
- Held-out set is tiny; it was written before the first run and not used for tuning, but it is still too small for reliable statistics.
- No example set was reviewed by native Hindi or Gujarati speakers or by fraud investigators.
- No test of adversarial scammers who adapt their wording to avoid the rules.
